# v0.4功能集成与实际图件试跑

本轮从已安装MathModel 0.0.23的实机操作中吸收功能关系，继续自有实现；不复制其私有程序、账户、品牌资产或用户历史。界面遵循使用者最新选择：纯白、纯黑、少量红、统一圆角。竞赛论文仍使用确认的比赛模板。

## 已接通的同一工作区

- 项目、六种工作方向、比赛/引擎和个人模型账户选择集中于输入区；按项目与会话保留本机草稿，刷新恢复当前项目与显式新会话。
- 五类真实CSV图型和带分支回路的图示适配器：选择字段、含义、单位和数据性质，绑定输入SHA；读取固定上游指导并运行本工作流适配器，保留统计、脚本、图源、PNG/PDF/SVG和采用记录。
- 源码编辑、独立成品预览、同屏查看、文件夹分组与筛选、窄屏文件抽屉，产物从对话/文件树/代码运行记录回到同一项目。
- 不依赖模型账户的直接Python运行、Typst/XeLaTeX编译入口；从所选源版本与完整依赖快照运行，记录退出/取消/失败，失败不覆盖旧成果。
- 源保存版本、只读版本对照、按当前SHA恢复并产生新版本；程序输出发布与源保存共用项目锁，先检查全部目标，避免并发保存/恢复被执行覆盖。
- CodeMirror按项目和路径隔离编辑状态与撤销栈；程序刷新不进入撤销历史，查看旧版本不改当前缓冲。

网页与Windows桌面共用界面。网页入口按当前站点共享设置访问，项目数据按登录用户隔离；本机模型密钥使用系统加密保存，模型代码不继承供应商密钥。网页云端隔离执行尚未连接，不把入口可打开当成云端建模已经运行。

## 实际模型与界面验证

MiniMax M3.1 Flash Preview经受限工具完成两轮独立图件试跑。

| 场景 | 实际证据 | 范围 |
| --- | --- | --- |
| UCI Iris | 固定官方下载版150行、4个cm变量；13次工具调用；真实适配器导出PNG/PDF/SVG和数据/合同/脚本；独立Pearson矩阵最大绝对差0 | 数据与绘图通信测试，未训练模型或完成竞赛论文 |
| 分支与回路 | 10次工具调用；原生draw.io、PNG/PDF/SVG；首次把外层说明混入合同后导出被拒绝，模型自行纠正 | 通用机制图，不证明数值算法运行 |
| 源动作 | 从实际网页文件区运行Python，得到结果14的JSON；从论文源编译得到实际PDF，无需模型账户 | 隔离的软件界面夹具，未作为赛事正文 |
| 保存/恢复/撤销 | 源编辑形成版本，界面恢复旧SHA并留下user_restore新记录；另一文件Ctrl+Z未带入前一文件内容，返回后原编辑仍在 | 项目/文件隔离与恢复回归 |

Iris来源是[UCI官方数据页](https://archive.ics.uci.edu/dataset/53/iris)，DOI 10.24432/C56C76，CC BY 4.0。下载的iris.data SHA-256为6f608b71a7317216319b4d27b4d9bc84e6abd734eda7872b71a458569e2656c0；只添加列名的CSV为20f7ef9ad6e85c0752a0cda4c9d1edfcad39c04114a822496a15c20eb1df2cda，保留全部行和值。UCI说明部分历史样本与Fisher原表有差异，本轮不混用其他版本。

离线知情审阅采用Sivia方法适配：统计PDF实际嵌入SimSun，流程PDF嵌入微软雅黑/Times New Roman；未见黑块、遮字或箭头压字。流程源包含原生对象、附着连线及三层，PDF无位图。旧通用示例的未收敛边缺少当前状态更新说明，已补工作流检查和新版示例提示；原试跑图保留为原始证据。论文嵌入、原应用live审阅与完整出版结论仍pending。

本工作流全部447项单元测试通过（4项按环境跳过），上游入口检查与skill校验通过。应用端实际D1/R2、原生SQLite/代码/绘图/版本/源动作6项回归通过；Windows0.4安装包构建及包内MCP、系统加密重开检测通过。安装包检测复用已有数值/排版组件，不能称为无依赖电脑完整开箱验收。
