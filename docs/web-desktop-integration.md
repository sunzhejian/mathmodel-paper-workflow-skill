# 新版桌面参照与集成工作区 v0.2

2026-10-04依据使用者提供的快捷方式、现有界面和设置截图，只读研究当前已装MathModel桌面包。旧安装器PE版本为0.0.3，已装包manifest版本为0.0.23；快捷方式是Windows应用标识`com.mathmodel.desktop`。这里记录本机指定参照，不把它称为公开渠道的最新发行版。

研究范围是包manifest、公开技能说明和14份比赛模板的元数据。未读取或复制账户、密钥、聊天历史、用户论文和私有项目；包内没有核实到可用于再分发该桌面产品源码/资产的许可。功能思路与布局用于自有实现；不能把jihe520/MathModelAgent的许可自动套到另一桌面产品。

## 实际实现和验收

Sites源码对应`84e226c1446801cd6258d893f764d004b6c165c7`，保存为v0.2后成功部署到[同一私有站点](https://sunzhejian-mathmodelagent.sunzhejian.chatgpt.site)。D1保存项目/材料/逐问/事件，R2保存不可原地覆盖的原件。8MiB分片、单件最大512MiB；服务器全量SHA-256；≤2MiB的UTF-8 CSV/TXT/MD/JSON/TeX/Typst提供词法读取。其他格式或超出解析范围的文件保留原件，并标记待解析或有限范围。

每问保存完整要求、原题位置、资料使用目的/必需性、前问依赖和人工输入核对。服务使用Sites用户身份并核对项目所有者。科学执行与科学核验状态保持未开始；人工输入准备不代替模型运行。

Miniflare实际D1/R2测试通过，覆盖用户隔离、无身份拒绝、跨站写入拒绝、CSV字面小数/空值/引号、8MiB以上分片、缺分片、原件下载字节一致、完成后重复请求、R2已合并而D1未更新的断点恢复、恶意问题ID拒绝、序号唯一约束、多窗口版本冲突、并发依赖变化与循环防止。浏览器用匿名合成题面和CSV实际走过保存、上传、绑定、刷新恢复和逐问再次保存；没有上传真实赛题作为线上测试数据。

MiniMax M3.1 Flash Preview通过已授权的中国订阅编程客户端进行一次只读源码复核，返回3项问题；原生子代理复核另发现2项并发/恢复问题。已补服务器生成的问题UUID、原子版本条件、数据库序号约束、依赖图校验和合并后恢复路径，并加入真实存储回归。模型输出属于审查建议，修复是否有效由实际测试判断。

Windows下官方发布准备器已保存并推送源码，但其包步骤因跨Shell路径失败；采用本项目可复现的打包器，只收同版Worker、声明和Drizzle迁移，逐文件比对字节，最终通过原生Sites保存/部署返回成功。没有为打包改系统默认Shell，也没有改已经应用的迁移记录。

## 下一轮优先顺序

1. 接可信独立执行节点，读取完整原题/附件并显式加载所需上游指导，按问题运行与核验；支持恢复、取消和同版事件。
2. 接源文件编辑、实际PDF/表格/图件预览与论文编译；检查摘要分页、数学字体、完整公式、图文遮挡和页数，避免把预览错误留到交付。
3. 用用户提供的完整实题，在干净节点跑每问代码、真实图表和20页以上论文及支撑包；保存模型实际使用参考的证据，软件通路和科学验收分别记录。
4. 完成当届模板字段/队伍档案、真实使用情况、协作与归档；只在对应能力接通后提供操作入口。
