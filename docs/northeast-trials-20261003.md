# 2026东北三省A题：完整输入的阶段试用

本记录与早先的合成小题、冻结现稿排版回归分开。使用者提供完整原题、人口普查数据 ZIP 和原封面 DOC，目标是由外部模型完成20页以上论文及全部支撑材料。此处记录的是已执行的资料审计与接续阶段，**尚未完成该完整交付**。不修改早先论文，不以宿主补写科学程序或正文替代模型产物。

## 输入与运行边界

原题为2026东北三省数学建模联赛 A题，要求四次人口普查的区域分类、影响因素变化、分类人口预测及有/无政策情景比较。完整原件留在使用者授权的私有项目；本仓库不发布赛题附件、真实数据、参赛正文、账号、密钥或模型私有原答复。

数据 ZIP 有441份原文件，另包含目录项；主数据索引中的349行是文件/工作表引用，不能当成349份唯一原文件。原件复制保留字节与哈希，所有可访问工作表作词法投影，未选科学字段、改单位或填数值。305份旧 XLS 无法读取，使用者确认在 Excel 中也打不开；没有猜密码或解密。扫描 PDF 提取的页码标记仍不属于表中数据。完整材料已提供与科学输入已建立分别记录。

模型使用已安装 OpenCode 1.18.34，通过使用者已授权的 Coding Plan/Agent Plan 与可选[项目试用接口](../references/workflow-project-trials.md)运行。模型写分析、数据读取代码和后续修订；宿主只准备原件、通用工具、审阅源码允许执行、核对实际结果并反馈缺陷。解释器、文件读写和排版后端由宿主明确指定；此接口不是操作系统沙箱。

## 发现的问题及通用改进

| 真实发现 | skill 的改进 | 验证范围 |
| --- | --- | --- |
| 将扫描 PDF 的导出标记误作有效文本 | 区分原页、原生文本/OCR、核验科学输入；新增 `extract_scanned_pdf.py` | 保存来源页、识别框/分数、原件前后哈希；仍需核对数字与表格结构 |
| 现代 RapidOCR返回属性对象，旧元组拆包失败；另一程序只探测旧包 | 先检查真实后端、已存在模型和返回结构；适配已知新旧返回 | 合成扫描页实际后端烟测与输入/缺失/非法返回回归；不宣称中文表格准确率 |
| 以工作表索引行数充当原件数量，按sheet序号猜表意 | 文件与工作表分开计数，实际核对表头、单位、地区标签及跨年口径 | 资料审计反馈与写作/求解交接要求；尚未认证人口数据矩阵 |
| 文字里模拟工具调用 | 保留原答复，标记没有执行的工具意图，拒绝计为有效工具完成 | 客户端正常结束与真实执行分项；不是通用AI真实性判别器 |
| 旧稿数学关系碎裂为编号单变量 | 新增 `check_formula_integrity.py`；排版接口编译前/后拒绝严重碎裂 | Typst源码和真实PDF结构回归，旧稿仅诊断未改写；不证明推导正确 |
| 上游被提名不等于采用 | 默认按阶段实际读取参考，记录采用方法与对象 | 三模型均实际读取 MathModelAgent；DeepSeek/GLM另有BZD记录，Kimi该阶段仍缺所需BZD读取，不计完整采用 |

旧公式碎裂经定位来自原有宿主段落转换器：它把带空白的 Typst 行内数学转成独立块，并错误处理数据字段下划线。该缺陷不能记作外部模型自行犯错。新任务直接编写完整关系并检查源与PDF，不再复用该转换器；原有稿件保持不动。

上述通用改进已通过447项本地工具回归，含真实 Typst 编译与两次求解覆盖同名CSV后旧/新字节恢复；它们不计为完整实题的科学或论文成绩。宿主另对原件两份扫描PDF共257页作逐页渲染/转写尝试，保持原件SHA；空识别页保留 `limited` 和原页，不删除或认证其数值。模型使用新的冻结材料包接续，旧输入与各自既有产物保持不动。

## 下一阶段的准入

先由模型建立可核对的四次普查输入，明确行政区划、字段和分母口径，再实现全部四问。缺少的必读规范需要实际补读；数据或程序错误由该模型修订并提交新的完整代码树审批。宿主不会补人口分类、预测模型、政策效应或论文段落后记作它独立完成。

通用扫描转写仅补材料读取能力，保留原页与未验证标记，不提供参考解法。达到完整交付时仍需单独核验科学结果、同版图表、摘要分页、公式、21页以上的本次页数合同、真实AI披露、文献和全部支撑材料。请求模型名、工具调用或单元测试数量均不能代替这些条件。
