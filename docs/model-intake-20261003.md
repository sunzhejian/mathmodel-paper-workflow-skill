这是原题输入与分析交接试验。只读 MCP 不执行求解和编译，因此本轮不计作 21 页以上论文及全部支撑材料已经完成。原始材料、原答复和完整日志保存在本机独立研究目录，公开 [观测元数据](../examples/model-trials/input-handoff-observed.json) 不包含实际赛题、数据或参赛正文。读者可用自己的授权题面按 [材料合同](../references/case-materials.md) 重建入口；通用接口及合成测试可直接从仓库复现。

原答复保持不变。DeepSeek 的部分有效事实字段和 GLM 的完整 JSON 对象只作只读来源核对，不把提取片段或去掉前言后的对象当成原答复格式合格。两份原始数据的行数、时间范围、采样间隔，以及四问电子输出间隔另作了限定核对；没有给模型设计或整篇论文综合评分。

## 缺口定位与同题重新测试

项目原有 [证据与写作](../references/evidence-and-writing.md) 已要求分别核对正文展示范围和完整电子结果范围。第一轮模型实际只读了本项目入口与上游分析入口，没有加载这份必要参考。因此改动落在阶段上下文交接，原有正确规范保持不变：

1. 主持方用 `--required-project-file` 选择本阶段必读的项目规范与上游引用；其他阶段按自己的必要文件选择。
2. 材料收据和规范收据分开检查；文件存在或主入口已读不代表被引用的规则已经送达。
3. 注册 MathModelAgent 的共享 `_references` 入口，让分析技能引用的知识文件确实可读；它是知识来源，不是单独执行的任务。
4. 在分析交给代码之前，分别记录观测范围、正文抽样范围、完整输出范围、计算范围及终点依据。

Kimi 使用相同原题、原数据和输出样表重新开始一个会话，读完 14 项材料及 5 份必读规范，23 次工具调用，183.4 s 正常结束。新原答复可直接解析为 JSON，自行区分正文前三小时与完整过程电子输出，并指出精确终止时刻及四小时之后的环境闭合需要建模处理。没有人工替它改答案，也没有将第一次答复作为新会话输入。

这是针对已知问题的同题回归。它不证明对新赛题的普遍提升，耗时也不被解释为 skill 质量分数。后续还须实际求解、核对全量结果、绘图、继承模板、编译并检查最终论文与支撑包。

本地最终运行 334 项单元测试全部通过，无跳过；包括完整材料合同、流式读取、冻结文件、分页覆盖、阶段规范收据、SVG/字体与摘要结构，以及数据图和流程图接口。测试数量只说明列明的工具回归，不能换算为竞赛论文质量。
