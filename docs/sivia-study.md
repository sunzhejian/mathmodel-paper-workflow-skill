## 长稿试用暴露的项目缺口

2026-10-02 的匿名合成题覆盖需求预测、整数车队、库存、有限情景与敏感性；用户选择“20 页以上及全部支撑材料”。本轮外部模型会话关闭工具，模型交回源码/文字，宿主实际执行、绘图、装配与编译。这些是纯文本生成与宿主辅助实验，不能据此认定其他 AI 已会使用项目。

| 实际现象 | 最早负责的步骤 | 已补充的项目指导与验收边界 |
| --- | --- | --- |
| DeepSeek 初版预测使用的日号不一致，独立核算发现多项结果偏差 | 求解的日期/样本 ID 接口 | 先固定真实日号与数据范围，逐日表和指标由同一结果导出；修求解后更新图文 |
| Kimi 初版把验证情景网格当成测试网格 | 政策选择与评价的数据接口 | 验证选择、冻结政策、测试评价分开；完整网格保留范围，独立核算分别检查 |
| GLM 会话出现 `length`，客户端退出码为零却没有完整答案 | 客户端会话完整性 | 结合终止原因、完整答案和产物判断，截断保持失败/待接续 |
| Kimi 原始文字由宿主装配后仅 19 页，未达到本次下限 | 写作的证据预算与全文验收 | 回到有证据的论证缺口扩写；宿主新增内容单列，不计为模型自主完成 |
| draw.io SVG 含 `foreignObject`；Typst 编译警告但退出成功，PDF 中出现黑块与丢字 | 图件导出与嵌入兼容 | 同源可移植 SVG/高清 PNG，保留可编辑与矢量源，核验实际 PDF |
| 宿主装配源使用 `Noto Sans SC` 作为中文正文 | 模板/字体选择 | 先遵循模板和用户字体要求，发现真实 family，检查字体职责及最终 PDF |
| 用户指出摘要与正文同页；宿主自造入口未使用上游的摘要换页宏 | 模板复用与结构合同 | 读取实际模板及宏，新稿沿用完整所选模板，旧稿修宏调用/分页，再检查真实 PDF |

黑块图原本要说明“冻结预测和库存政策后，用历史库存确定订货，再做整数车队决策与服务评价”的信息时序；图意由题目和模型关系确定，黑块来自渲染失败，不能作为有效图件交付。科学条件和箭头关系须保留，制作诊断留在后台。

本轮据此补充[渲染合同](../references/rendering-contract.md)、阶段能力发现和[真实项目工具试验](../references/model-trials.md#真实项目工具试验)。宿主补稿、固定字符串修正及装配原型留在内部 QA；后续宿主修订形成的实验稿不作为原模型的完整长稿成绩。实际模型自主读取、调用工具、纠错和交付的结果须另有运行证据，不能用上述 77 项上游测试或论文编译成功替代。

再次读取固定 MathModelAgent 的 `5writing/SKILL.md`，其明确要求“存在匹配模板时，绝不从零开始写论文”。所选 CUMCM Typst 模板 `abstract-cn` 已有 `pagebreak()`，LaTeX `abstractcn` 已有 `\newpage`。摘要结构失效来自宿主原型绕过已提供模板；应复用实际模板和记录具体规则来源，不能以增加另一套自造入口掩盖这个缺口。共享知识库“中国赛摘要一般不超过两页”也不能覆盖本次用户要求的独立一页。

首轮真实项目试用若仅验收字体/SVG，即使相应 PDF 达到 25 页，也只计这两项恢复；缺少摘要结构验收时不能称完整排版成功。后续增加摘要单页合同的试用使用新工作区，记录代理读取上游模板、实际工具调用与最终 PDF 结果；当前未运行结果不预先标通过。
