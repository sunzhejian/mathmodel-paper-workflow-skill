仓库包含技能协作说明、复现手册、上游版本记录、约束合同、合成演示和三张可编辑讲解图；四个上游技能项目以固定提交的 Git 子模块放在 `vendor/`。本项目维护的MCM LaTeX/Typst模板位于 `assets/templates/en/`，初始化、盘点优先级和PDF边界/页眉检查已实现；原上游和既有用户论文没有被覆盖。项目清单检查、PDF审核和科学内容审查各自保留检查范围。

## 如何复查

从仓库根目录执行复现手册中的环境和演示命令。首次克隆须带 `--recurse-submodules`；已有仓库须运行 `git submodule update --init --recursive`。GitHub Actions 在Windows/Ubuntu核对上游并测试，下载固定Typst 0.15.1、校验官方资产SHA-256后运行真实Typst编译；XeLaTeX存在时运行其编译检查，不存在时明确标记跳过。用户运行测试可用 `MATHMODEL_TYPST_EXE` 或 `MATHMODEL_XELATEX_EXE` 指定已有可执行文件；测试不自行下载或安装工具。远端状态见 [Actions](https://github.com/sunzhejian/mathmodel-paper-workflow-skill/actions)。draw.io渲染与人工视觉检查另行记录。
