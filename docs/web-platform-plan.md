# Sunzhejian的MathModelAgent 网页版开发计划

2026-10-04用户明确将网页版列为重中之重，替代此前仅优先便携发行的排序。项目名称为 **Sunzhejian的MathModelAgent**，面向**东北农业大学数模协会办公室**，采用中国古典水墨风与宋体。网页是新增可选入口；直接在使用者IDE调用 skill 的方式继续保留，网站不会成为调用前提。这些计划与后台记录不进入竞赛论文正文。

## 产品方向

首屏是可操作的建模工作台：先确定工作大方向，再导入完整题目与资料、选择当届比赛/模板，组织每问建模、真实求解、图表、论文与交付。完整全交付、已有结果写稿、修订现稿、审查、制图、排版六种方向分别接续所需阶段，不要求所有人重走完整流程。

以 [MathModelAgent](https://github.com/jihe520/MathModelAgent) 为主要融合对象，当前研读固定版本 `487f350` 的真实 Vue/FastAPI/Jupyter 工作流和模板；参考 [mathmodel.top](https://mathmodel.top/) 的产品定位。网站入口当前重定向登录，未声称体验其登录后的全部功能；具体实现依据来自已读取的项目源码。[融合映射](web-upstream-integration.md)列出实际文件与适配边界。

视觉采用宣纸底色、墨黑、少量朱砂、细分隔线与清晰宋体层次。风格用于工作台，正文继承选定比赛模板，不把网站品牌、协会名、制作记录或UI口号写进匿名论文。图库展示来源清楚的示例，数据图以当前真实结果重算；模板图的模拟数值不能进入正式成果。

## 架构与融合

- **Sites网页层**：工作台、方向问询、材料台账、比赛/模板选择、图表目录、任务与成果查看。先发布交互预览，明确实际已实现项；不以动画模拟求解或编译完成。
- **项目与任务接口**：从 MathModelAgent 的项目/上传/任务/文件界面与事件协议建立适配层，接本 skill 的实际阶段、原题要求、文件哈希与采用记录。上游四 Agent 提示词不会因为 vendor 存在就自动使用我们的六阶段指导，必须显式加载所需 skill/引用与任务合同。
- **独立执行服务**：Python/MATLAB/R求解、OCR、统计制图、draw.io及Typst/LaTeX编译由实际具备工具的执行节点处理。Sites的Workers层处理界面/请求，不能宣称它已经具备本机Python、Jupyter或完整TeX环境。
- **模型适配**：保留DeepSeek、GLM、Kimi等真实可用路线与角色分工。订阅套餐只按其允许的编程客户端使用，不把现有Coding/Agent Plan凭据改成网站公共API后端，也不自动切换按量付费。后续服务凭据与用户/任务隔离在服务端实现，不照搬上游浏览器持久化key和全局配置修改方式。
- **成果与检验**：连接原题全部问题ID、代码/输入/结果版本、真实运行、专项科学检验及成品。机械文件完整只是一层；公式碎裂、摘要独页、字体/图件、样表范围及科学证据分别验收。

## 按可验收成果推进

**首版实际状态（2026-10-04）**：[Sites交互预览](https://sunzhejian-mathmodelagent.sunzhejian.chatgpt.site)已部署成功，保持创建者私有访问。界面为宣纸白/墨黑/朱砂红与自托管宋体风格字体，包含六方向、材料选择/分类、当届模板偏好、五类合成图示和配置导出。公开数据图只提供预览，真实生成、AI求解和PDF编译尚未接服务。MiniMax源码复核意见与宿主语法/浏览器核对分别记录；本轮没有修改竞赛论文。

**v0.2实际状态（同日后续发布）**：同一站点已升级为持久项目工作区，原件保存/分片/哈希、有限文本解析、逐问要求与依赖、资源选择、真实过程和设置共用项目。源码版本`84e226c1446801cd6258d893f764d004b6c165c7`对应Sites成功发布；科学执行服务尚未接通。参考使用者指定的当前已装桌面包0.0.23，旧安装器0.0.3不作为新版功能基线。详见[新版参照、边界与验收](web-desktop-integration.md)。P0-B只完成材料与任务登记部分，P0-C/P1的运行能力仍需实际接通。

设置按新版截图形成后续模块：论文/当届模板与队伍档案；模型与供应商；运行环境、网络与系统提示；外观、快捷键、通知；真实使用统计与说明。优先接同一项目的运行能力和文件预览，个人统计只能根据真实事件产生。团队字段只有模板明确要求时进入对应页面；不得把桌面账户、订阅或私有历史复制到公开资料。竞赛日历、协作、分享与自动化在功能实际接入后提供操作入口。

网页可先上线预览，不等于 P0-B/P0-C 的后台与科学能力完成。当前独立人口题试用记录另见[实题阶段记录](northeast-trials-20261003.md)；其材料阶段与完整论文分别计，未被网站预览补作通过。
