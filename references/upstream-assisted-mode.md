# 默认参考项目协作

当前默认采用 `upstream-assisted`：本 skill 组织任务与交付，阶段方法同时读取实际可用的参考项目。使用者不必另外调用多个 skill；代理按任务在同一入口中完成。自主模式尚未达到全流程迁移验收，不能由代理自称“已经成熟”后静默切换。

## 各阶段实际采用

| 阶段 | 必读来源 | 在当前任务落实的方法 |
| --- | --- | --- |
| 读题与建模 | MathModelAgent `2analysis-modeling`、共享 `_references` 对应部分；涉及假设时读 BZD `bzd-model-assumption-checker` 及假设规则 | 覆盖每问及输出要求；区分题面事实、闭合假设和未知量；不能通过假设删除题目难点 |
| 实现与求解 | MathModelAgent `3coding-visual`；BZD `bzd-model-solution-checker` 的模型、检验与灵敏度对应部分 | 自行实现并实际运行，每问保留入口；检验匹配模型；完整电子结果与正文抽样分别验收 |
| 数据图 | MathModelAgent 绘图规划/模板；EditaPlot `data-contracts`、`chart-selection`、`figure-contract` 等与该图有关的知识 | 核对真实列、单位、样本/群组标识、统计口径与分析/显示变换；图型由数据与要回答的问题决定 |
| 示意图与复杂流程 | sci-box `scibox-diagram`；Sivia `design-scientific-figure` 与 `audit-scientific-figure` 的相关工作流 | 关系和条件有依据；保留可编辑源；审查负路径、关键操作数、箭头、实际缩放和可读性 |
| 写作与排版 | MathModelAgent `5writing` 及当前实际模板；选择 Typst 时读 `typst-author` 的所需数学/文档语法 | 继承真实模板；结果确定后写摘要；完整数学关系保持整体；行内变量、编号公式与数据字段采用各自正确语法 |
| 最终验收 | MathModelAgent `6verity`；本题必要的 BZD 模型/假设检查；有科学示意图时再读 Sivia 审查规则 | 对照题意、代码、全精度结果及最终文档，定位实质错误并回修；不把编译成功、文件齐全或上游评分称为模型正确 |

只读当前阶段需要的章节，不要求所有任务运行全部专用工具。EditaPlot 的 Origin 执行要求、Sivia 的可选实时工具、固定迭代次数和上游自评分不成为跨环境调用的统一前提。对知识做通用适配时记录 `adapted_from`；实际没有运行 Origin/PowerPoint/MCP，就不能记录为这些工具已执行。

当前本地入口由 `vendor/skill-integrations.json` 定位，锁定提交见 `examples/upstream-lock.json`。知识文件只提供指导，不是单独执行的模型或分析。比赛官方规则和使用者明确要求优先于上游建议；不能把某个上游的固定页数、扣分、显著性或样例模拟数据搬进正式论文。

## 证明读过且用到了

完整论文任务在内部阶段报告中保留简短采用记录：

- 来源项目、锁定提交、实际读取文件及内容哈希；能取得宿主读取轨迹时一并记录。
- 本阶段采用的具体方法，例如时间划分、防数据泄漏、边界守恒、语义箭头、完整公式或摘要独页。
- 对应的本题位置/程序/表图对象，以及实际执行或审读得到的反馈；采纳与不适用项分别说明。
- 状态分别为文件存在、已读取、已用于设计、已落实在产物、相关工具已执行。状态不能仅凭模型自述或工具次数递增。

原文路径、哈希、调用日志和制作状态留在内部报告，不写进论文正文、摘要或模型优点。正文保留真实方法来源、学术引用及赛事要求的 AI 披露。

记录只能证明列明的读取与采用范围；不能自动证明模型理解正确。最终还要对题面、实际代码和结果审查。没有运行证据的规则不能靠填一句“已验证”变成执行成绩。

## 缺失与便携

发行安装内容应带齐本阶段必要参考及模板，使用者不必手工安装多个上游入口。缺失必读来源时明确指出路径和受影响阶段，由代理按已授权来源/版本补齐或报告不可用；不能静默改为纯自有方法，也不能宣称该阶段已完成参考项目协作。取得真实文件前可继续与其无关的数据盘点等工作。

上游指导按许可保存来源，不要求特定账户、IDE或本机目录。不同宿主通过现有读取、程序运行、绘图和编译工具应用相同阶段方法。开发专用的 MCP 读取收据只是某条试用路线的证据，不是普通使用者的配置要求。

## 何时考虑自主模式

只有在未参与调优的新题上完成真实求解、科学检验、模板写作和支撑包复验，并检验不同环境下的调用后，再评估减少哪些外部指导。按方法、题型及交付范围记录回归差异；单篇达到页数、同题修复或单元测试数量不代表成熟。默认协作方式的改变需要使用者明确选择，不能自动省去尚有价值的参考。
