# 数值实现与结果文件合同

适用于数值求解、时空场输出或题面给出电子结果样表的任务。先读取 MathModelAgent 的 `3coding-visual/SKILL.md` 与其共享规范中本题需要的章节；这里补充实题试跑发现的交接缺口，不替代建模推导，也不固定某道题的参数。

## 原式到实际代码

- PDF提取文字会丢失分式、负号、下标及单位。含关键公式的原页应通过宿主真实图片/PDF预览能力核对，再记录所用公式和页码。支持图片的模型必须确实收到图像；工具仅返回文字、模型未声明图像能力或只生成了PNG文件，都不能记为已看原页。
- 对扩散/导热等守恒型问题，从同一离散方程追到实际系数和共享面通量。检查材料系数是否被重复相乘、相邻控制体的同一面通量是否一致，量纲是否对应。选择本题适用的常系数对照、守恒/边界检验及网格或步长变化检验；一段代码退出0不替代这些证据。
- 有移动边界时，写清固定空间位置、材料位置、计算坐标及输出位置之间的关系。导出域外空白只是输出处理，不能据此认定收缩域的输运或守恒模型正确；单纯修改半径或删除外部节点仍需与推导核对。

题面已经明确的方程结构直接遵守；不再询问是否删除已给项，或是否加入题目没有给参数的新项。常规算法选择由代理根据数据与计算条件判断并说明理由；只有改变题义的未定条件才向使用者集中询问。

## 求解与导出分别验收

在实现前把正文展示与电子文件输出分开。后者记录源样表、工作表名、列的物理量/单位、起止范围、采样间隔和额外终点。正文只展示前三小时等局部时段时，完整工作簿仍服从其全程要求。

原样表的省略号可能只是示意中间行/列，不代表结果只能有样表展示的数量。展开方式须绑定原题要求与坐标范围，不能按省略号字面复制，也不能任意换一套表头。工作簿检查器遇这种样表时要求显式 `expected_header` 与 `header_basis`（来源文件/SHA、位置及展开理由）；仍保持样表省略标记以外的固定头。辅助原精度文件的自有表名与正式电子样表分别判断，不把辅助格式差异误判为正式提交格式错误。

用坐标值查找/插值抽样，而非猜列号。若网格间距为0.1cm，0.5cm对应第5个零基网格索引；循环变量或相似表头不能代替实际坐标。将正文CSV或表格数值与同一版未舍入场数据按时间、位置、单位逐项核对。温度导出前确认摄氏/Kelvin转换，末列“表面”等名称须核对其物理量，不能误写成几何半径。

严格阈值由未舍入值判定。保存事件时间及该时刻的完整状态；若电子文件按固定间隔记录，终点可作为额外一行或题目允许的独立事件文件，但必须可追溯。最后一行显示0.1500不证明原值小于0.15，规则样本行也不等于实际事件终点。

结果和中间量使用语义不同的文件名，如 `time_seconds.npy`、`temperature_kelvin.npy`、`concentration.npy`。不能用仅大小写不同的 `t.npy/T.npy` 区分数据；Windows等文件系统会覆盖。生成前核对计划路径的casefold冲突，生成后检查实际数组形状、单位及时间轴长度。

## 可选机械核对器

`scripts/check_result_workbook.py` 只读地比较已经生成的XLSX、原始样表及声明的合同。它核对表头/工作表、时间序列、末值条件和指定正文CSV样本，不运行模型、不修改论文或工作簿。

```sh
python -X utf8 /path/to/skill/scripts/check_result_workbook.py --contract reports/result-contract.json --project-root . --report reports/result-check.json
```

按本题编辑 `examples/result-workbook-contract.json`，使用本轮实际文件SHA。正文CSV的每个 `column_mappings` 必须绑定已核对的工作簿列；单位换算通过 `scale/offset` 明确描述。阈值检查要求 `result.value_precision` 声明为 `unrounded`，这个声明本身仍需来源证据。合同通过只表示覆盖的机械检查通过，不能升格为方程正确、事件真实或完整竞赛交付通过。

宿主不具备这份脚本的依赖时，可用其已有工具执行同等检查并留下实际结果，不要求使用者配置本仓库的研发接口。

## 长任务接续

每个子问先运行可定位的最小检查，再扩展到全量计算与输出。将已通过的源/结果版本、当前失败、下一步留在后台阶段报告；遇同类错误反复重写整套求解器时，先定位最早失败的函数或离散项，保留已通过部分。超时、上下文压缩、模型会话结束、部分文件生成与完整交付是不同状态，不把阶段草稿计为成品。

调用宿主工具时以实际发现的接口为准。缺必填参数、版本冲突、权限拒绝与执行错误分别处理；先读具体错误和字段定义，不重复更换路径绕过检查，也不把缺参数直接归因为工具故障。宿主提供独立的新建/更新入口时，新建只作用尚不存在的路径，更新读取最新源版本后再提交；不为消除报错默认覆盖已有文件。

误差尺度由本题单位、参数不确定性、求解精度和实际收敛证据决定，不给不同量硬套统一极小容差。四位小数是输出格式要求，不自动证明四位精度。当前检验已达到有理由的误差目标后推进结果导出和图表；只有新的变化、失败或未解决问题才追加同类计算，不用检验数量替代逐问完成。

图件导出后查看实际图像，论文编译后查看实际页，记录所看页面/图件及版本。摘要独页、字体、公式完整和图表可读须落实到最终PDF；一张图片探针通过只证明该读取链，不证明整份论文版面正确。全部开发诊断和文件核对留在 `reports/qa`，论文只写有证据支持的数学与科学内容。
