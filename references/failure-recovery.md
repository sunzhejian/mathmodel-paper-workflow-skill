# 常见失败的定位与恢复

按现象选择一行处理，不把全部检查强加给简单修改。保留当前失败产物及日志，修订后生成新版本，避免“修好”覆盖了定位证据。

| 现象 | 先核对 | 修复动作 | 再验收 |
| --- | --- | --- | --- |
| 中文上方出现横线、图例旋转 | 原始图是否已有；是否用了竖排字体、错误字体回退或文本装饰 | 在绘图源中明确普通横排中文字体；独立预览正常后重新导出 | 单图 + 嵌入正文后的 PDF 都看；换软件不等于问题已解决 |
| 图外框未满版心但主体很小 | 图内白边占比，最外侧轴标和图例位置 | 调整画布/可见主体宽度后等比例放大 | 字号清楚、内容不越界、不把整图推成多余一页 |
| 表后半页空白 | 强制分页、整表不可拆、段后同页、浮动体尺寸 | 先释放无必要分页；就近排图/正文；长表重复表头续页 | 上一句没有断词，下一问未插入上一问结果 |
| 调一张图影响后面数页 | 浮动队列、标题同页、行距和图注 | 局部调整并重编译整篇 | 全文联系图和新问题页；不能只看原页号 |
| 自动留白通过但视觉仍空 | 指标是否被页内小标记/横线影响；是否是侧边/图内白区 | 按可读性检查真实版面，不用增加点线规避指标 | 记录人工观察；必要时修图源而不是改阈值 |
| 公式显示原始命令 | 命令是否进入纯文本、转义是否重复、转换链是否丢数学环境 | 从源修复数学对象/环境再编译 | 抽取文本扫描 + 原尺寸公式视觉检查 |
| `??` 或图号不一致 | 辅助文件、label 重复、交叉引用轮次 | 修 label；用原构建工具编译到稳定 | 日志无未解决引用，正文指向正确图/表 |
| 符号表一格有多个符号 | 是否打包写了多个量与单位 | 一行一个量，写出完整定义；首次正文给单位 | 表与公式及代码变量含义一致 |
| 摘要结果与表格不同 | 是否混用了历史运行、单位或舍入方式 | 追溯原精度结果，只更新受影响的派生产物 | 同一数值的摘要、正文、图、表逐项对照 |
| “知网可查”无证据 | 真实检索结果与完整书目信息 | 记录题名、作者、来源、年份、检索入口、核验日期和支持的论断 | 能匹配条目再使用；仅出版社/期刊核验不能冒称已验证知网收录 |
| 附录页脚非空 | 旧页码、扫描污点、线条、实际页脚高度 | 保留原页；已有页码可按约定沿用。需要改变方案时指出具体冲突 | 不自动白块覆盖；任何改动需符合用户授权并重新比对 |
| 附录像素比对失败 | 旋转、字体替换、页面尺寸或重建转换 | 回到原 PDF 页拼接，定位失败页 | 文本和渲染均一致才交付，不能只比较页数 |
| Word 比 PDF 多页/公式坏 | Word 字体、公式对象、浮动图、表格行高 | 在 Word 源中修复并单独渲染 | 分别给出 Word 与 PDF 检查结果，不承诺完全同版 |
| ZIP 缺结果/夹入题面 | 白名单与最终交付目录是否一致 | 明确区分题面、处理后附件、原结果、展示表；更新白名单 | 回读清单与哈希，并人工检查内容匿名性 |

## 命令失败的含义

- `audit_contract.py --dry-run`：只校验并打印参数，不生成报告或页图；不是验收通过。
- `audit_contract.py` / `pdf_workflow.py audit` 返回 `0`：自动检查项通过，仍须完成视觉和内容检查。
- 返回 `1`：有留白、页数或疑似公式问题；查看报告中的 `failures` 和对应物理页。
- 返回 `2`：配置/路径/输入错误。修复参数后再运行，不能把它当排版缺陷。
- 合同入口要求新报告和新预览目录，例如 `qa/round-02/layout.json` 与 `qa/round-02/pages`；避免覆盖前一轮证据。
- `append` 的失败不能绕过保真检查。需要有页脚修改等特殊处理时另行实施并验证，不能把放宽比对写成“原附录不动”。

## 结果变化的处理

纯排版修订如果数值发生变化，先停止更新摘要和交付包，排查是否拿错运行结果。确定需要修正模型或求解时记录原因、旧值、新值、受影响图表和复验范围；科学纠错优先于保持旧结论，但不能静默混用两个版本。
