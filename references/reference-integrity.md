# 专业文献工具与真实书目（适用于全部比赛）

使用宿主已有的专业工具：Crossref核对DOI与出版元数据，arXiv核对预印本ID与版本，Zotero管理真实资料库、原文及笔记。工作区支持本机/在线Zotero连接、实际检索、来源回读与BibTeX导入；连接之前先核对实际启用状态，不把安装、检索摘要或书目导入称为已读全文。EndNote等软件可按其实际支持导入BibTeX，不声称已运行未使用的软件。

先按研究问题检索，再核对题名、作者、年份、期刊/出版社、卷期页码及DOI/稳定出处；预印本、正式版、勘误、撤稿分别处理。文献必须能回到实际来源，不能用模型记忆、相似题名或看似合理的DOI补齐。重复文献去重，不为填满数量添加无关引用。确实不存在DOI的中文论文、图书或政府文件，保留原始期刊/出版社/主管机关的实际出处及人工核查记录，不伪造DOI，也不因有DOI就免查内容。

工作区工具链：`list_connectors` → `search_references`/`lookup_reference` → 实际阅读与摘记 → `import_reference` → 回读`paper/references.bib`的SHA → `audit_references`。本次导入来源会持久保留，当前BibTeX的作者、题名、年份等被改动后不能继续标成原来源已核验。Zotero本地元数据仍须与原始来源交叉核对；仅库内有条目不能证明真实发表。若DOI不在Crossref索引中，先到原始期刊/出版商或学术机构页面真实取证；可用`import_reference_from_capture`逐项匹配题名、作者、年份、DOI（如有）和页面语言再导入，保留截图与SHA。它证明实际页面元数据匹配，不等于全文阅读或论文结论验证；不能在任意营销网站制造一页书目后冒称已核验。旧项目可重新回读来源并去重导入以补齐来源记录，不覆盖用户正文。

## 文献语言规则

- 国赛CUMCM、正大杯、MathorCup等中文比赛，以真实中文参考文献为多数，外文原始研究按主题需要搭配。政策网页和新闻不能用来凑学术综述的中文篇数。
- 美赛MCM/ICM使用原始英文文献。中国作者发表的英文论文可以使用，中文论文机翻题名不算英文原始文献。
- 其他比赛按用户确认的论文文种执行。文献语言看原始出版物，不按作者姓名、国家或当前引用样式推断。

语言字段缺失时保留待核，查原始页面/全文或可信资料库补证；不得为通过比例检查直接填写猜测值。`audit_references`是书目、来源绑定与语言的机械检查，不替代逐条阅读、事实支持、撤稿核查或最终人工审查。未通过核验的条目不作为已核验参考文献进入终稿。正文引用的每项主张须能对到实际读到的页码/章节/表格，引用数量多不证明研究充分。

其他宿主可用等价文献管理、DOI查询及文件工具完成同样核验，不要求固定产品或连接器。
