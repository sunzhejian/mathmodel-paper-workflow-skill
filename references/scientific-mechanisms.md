# 科研机制图与可编辑图件

用于机制图、模型总览、方法结构或复杂路线图；数据曲线仍按 advanced-figures.md 的真实输入合同绘制。Sivia 固定源位于 vendor/Sivia，其设计、审阅和纠错入口供本阶段按需读取；新论文不一次加载全部参考文件。

## 先表达科学内容

先用一句话确定图要让读者理解的主要关系，再从题面、推导或结果列必要对象、方向、条件与来源。用空间关系、实体变化、分支或反馈表现方法，不能只有通用方框名称。参考图可借构图与表达方式，不能借其中的科学关系、数字或结论。

复杂图可保存节点/边及证据合同；已有图的小修沿用合同，不强制重新制作长表。区分流程、数据流、反馈、相关和物理通量；含义不同的虚线不混用。控制量、边界、训练与预测范围及数据划分等会改变解释的条件必须可见，不作为可隐藏装饰。

## 选择可用工具并制作

- 读取所选 Sivia design-scientific-figure 入口及当前图型所需参考；用 sci-box 的 scibox-diagram/TikZ 作精确线稿和 draw.io 图，读取其 authoring/preflight 文档。
- MCP 未连接时沿用离线矢量路线，不编造工具调用。用户已要求完成图件时直接完成，不套用反复审批；初次构图选择确实影响方向时询问两三种结构方案，颜色变化不是新结构。
- 原生文字、几何、箭头和可重建表图分层；复杂插画/实测影像是独立素材。实际图源可编辑才能声明可编辑；整图 PNG 插入 PPT 不满足该含义。
- 生成概念插画时使用当前可用图像工具。必要对象、关系、条件和准确标签决定 prompt 完整性，不设上游模板的字符长度下限。实测图像和定量结果不得经过生成式重绘后当作原数据。
- 每条连接预留路径和箭头空间。分组、字体修改或修图后重新导出，防止图层遮箭头、文字增长挤压主体。图按实际版心宽度检查，不能通过不可读小字压缩内容。

## 审阅与最小修订

读取 Sivia audit-scientific-figure 的对应规则，检查来源与图意、连接方向、可编辑对象、真实导出、字号、遮挡和物理尺寸。其设计原则适配到当前可用后端；没有真实 PowerPoint 渲染就不记录 PowerPoint 已通过。

复杂总览可用无标题、灰度、简化细节视图检查阅读顺序；关键条件不隐藏。同一代理自审记录 self_review，知情审阅不声称独立盲审。局部小改核对受影响对象与整体最新导出，不重复未改变的整套审阅。

错误先定位到来源解析、设计、绘制或审阅，再给最小对象级修法。缺陷日志与制作说明留在 reports/qa，不能进入论文标题、图注或模型优点。只有跨案例反复出现且确能复现的修法才提升为通用规则。
