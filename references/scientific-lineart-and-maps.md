# 科学线稿与研究地图

## 科学单线矢量图
需要控制体、边界条件、几何结构、装置或科技线稿时，读取 `scripts/render_scientific_lineart.py`。它接受毫米坐标的可编辑 JSON 场景，支持线、箭头、尺寸线、圆、环带、矩形与文字，生成 SVG、PDF、PNG 和源场景。示例是有限体积机制示意，不代表本题已经求解。按本题真实几何、符号、法向和边界条件修改场景，再在项目内运行。

不要用生成式位图或自动描摹代替线稿。检查箭头方向、环带中线半径与厚度、中心/表面半控制体、法向导数和单位；在最终论文尺寸看 PNG/PDF，保留 SVG 与 scene.json。数学公式使用 mathtext，不执行用户提供的 TeX 命令。

## Shapefile 与地图
先核对同名 .shp/.shx/.dbf/.prj，不能根据数字范围猜坐标系。GeoJSON 使用显式 CRS 参数（RFC 7946 为 EPSG:4326）；投影用 PyProj，几何与孔洞用 Shapely，字段需来自完整属性表。使用 `scripts/render_research_map.py`，在本项目保留源 SHA、输入/输出 CRS、字段与导出记录。对缺失、无效几何和字段中断并报告，不默默修补或编造。

中国国界、行政边界与世界图必须遵照自然资源部《公开地图内容表示规范》（自然资规〔2023〕2号）。使用自然资源部标准地图服务下载原图，保留完整图幅、台湾及重要岛屿、南海诸岛与审图号；不能用 Natural Earth、模型生成国界或未经核验的网络边界替代。

严格底图模式接受 manifest：file、source_url、sha256、review_number。工具将本地字节与官方 HTTPS 下载比对，完整保留原图，不裁切、不重绘边界。官方来源不可访问或字节不符时停止；不得写“已自动审查合规”。公开使用前仍核对底图适用范围及需履行的地图审查。一般研究区矢量模式不认证其行政边界；大范围涉中国图幅会被阻止。缺少官方底图时可完成数据分析和布局，不能生成替代中国国界。

- 官方标准地图：https://bzdt.ch.mnr.gov.cn/
- 内容规范：https://www.fmprc.gov.cn/web/wjb_673085/zzjg_673183/bjhysws_674671/bhflfg/dtdmxgfl/202303/P020230313585504979937.pdf
- PyShp：https://github.com/GeospatialPython/pyshp
- PyProj：https://pyproj4.github.io/pyproj/stable/

## 全国与地方市调中的地图选择

研究设计时区分研究范围、计划抽样范围、实际回收范围、统计地域和底图范围。全国研究可选全国区位与样本覆盖、同口径地区指标比较；地方研究按省、市、县或真实研究区选区位图与样本分布。调查路线仅在保存了实际行程、点位和授权后绘制，规划路线明确为计划。地图应回答问题，不为填页机械加图。

先检查地域字段与粒度、行政代码和年份、分母、来源、时间、缺失及小样本。区域计数不能拆成各省数值，省级数据不细化到市县；无数据与零值分开，率与人数分开，不把均衡配额着色称为现实渗透率。统计范围未包括港澳台时保留完整国家版图，数据范围在图例中说明；缺测地区不得抹去边界或岛屿。精确个人住址不得直接公开，按可用的匿名汇总层级呈现。

地图方案可以是研究区区位、样本覆盖、同分母地区差异或有来源的政策设施分布；等值设色、点位和路线需要真实对应数据。原标准图完整置入，数据面板可放图外；专题编辑、拼接、缩放、增减内容或改变符号色彩均单独核对公开使用要求，原审图号不自动覆盖新图。

在 `reports/map-plan.json` 记录用途、地域粒度、研究/数据/底图范围、源表与连接键、数据年份、官方原图URL及SHA、审图号、完整图幅检查、编辑与公开使用状态。未取得可用原图时登记具体缺口并继续其他图文，不用生成式图片、自动描摹、国外轮廓或随意网络GeoJSON代替中国边界；也不把政府文章里的教学圈注图、截图片段当标准地图原件。证书错误不得关闭TLS校验或私加根证书。

核对依据：自然资源部《公开地图内容表示规范》（自然资规〔2023〕2号）；[标准地图服务系统](https://bzdt.tianditu.gov.cn/)；[福建省自然资源厅2026年标准地图使用说明](https://zrzyt.fujian.gov.cn/zwgk/xwdt/tpxw/202609/t20260921_7216251.htm)。四大区域解释可查[国家统计局划分方法](https://www.stats.gov.cn/zt_18555/zthd/sjtjr/dejtjkfr/tjkp/202302/t20230216_1909741.htm)，说明口径适用范围，不反称旧问卷已经采集省份。
