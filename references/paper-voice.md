# 论文表达：证据、自然衔接与局部改写

用于摘要、正文、题注和模型评价的写作或润色。用户说“穿帮”时，先结合原句判断问题：制作记录、模糊指代、虚构主张与多余辩解的修法不同。已经明确的局部修改直接完成；不为这项审查重新询问比赛模板，也不改用户保护的附录。

## 判断一句话的作用

| 原句的作用 | 处理方式 |
| --- | --- |
| 强调核心方程、关键参数或主要结果 | 有推导或结果支持即可保留；少量加粗或细黑框，公式编号在框外 |
| 解释模型选择、反驳具体替代解释、说明误差或适用范围 | 保留所需条件和理由，优先写条件、证据及其含义 |
| 表达真实不确定性，例如参数只能区间辨识、外推缺少观测 | 保留限定，说明不确定性来自数据还是假设；不能润色成确定结论 |
| 先道歉、空泛自我贬低、反复防备同一种假想质疑 | 合并或删除无信息部分，用现有证据直接说清研究内容 |
| “按你的要求”、制作指令、内部交接文件或验收状态 | 从科学正文移出；确有学术内容时重新表述，记录留在 `reports/` 或 `qa/` |
| “全面领先”“显著提高”“充分证明”等没有对应证据 | 回到推导和结果核对，缩小或撤回主张；不凭措辞造优势 |

**强调与必要的防御性论证允许存在。** 不机械禁止“值得注意”“需要指出”“不能”“并非”“可能”或对比句。判断标准是它是否改变结论的成立条件、澄清概念或帮助读者正确使用结果。“可能”有数据依据时保留；“显著”涉及统计判断时需要相应检验，而不只是语气更强。

## 将表达问题分开处理

去 AI 味与去多余防御共同服务于清楚、准确的论文表达。先确认主张及证据，再检查句段如何组织；风格改写保持原有学术语体，不加入虚构经历、口语填充、错别字或随机句长变化。局部润色只修改有具体问题的句段，其他内容保留；用户另行要求重构全文时，再按该范围处理结构。

| 可定位的问题 | 数模场景的处理 | 必须保留的情况 |
| --- | --- | --- |
| 对举先设一个并无依据的误解 | 判断这层对比是否增加信息，无信息时直接陈述结论与依据 | 模型假设对比、数值收敛与现实检验的区别、相关与因果的区分 |
| 新段直接评论，上文对象不明确 | 用已有材料补明具体变量、方案或结果，再解释意义 | 已有清楚回指、必要的适用域或明确解释 |
| 提示语引出一句普通判断，或反复宣布下文有列表 | 删除无信息的引导，让判断或步骤直接承接上文 | 定义、约束条件、算法步骤和读者需要的范围提示 |
| 连续句只重复同一骨架、同一空泛结论 | 在当前段内调整主次或合并重复说明，保留每条证据 | 并列实验条件、约束列表、同一指标的不同方案比较 |
| 泛化褒义盖住已有的具体结果 | 用原稿中已核对的数值、单位、基准和区间解释结果 | 不能凭空补数值、来源、检验或“显著性” |
| 多层保留词反复叠加 | 减少重复词，并保留真正的不确定性及其来源 | 参数不可辨识、样本外无观测、相关关系及条件最优等限定 |

不按标点总数、长句、被动句、比喻、设问或“首先/其次”来判断作者身份。比赛要求的章节编号、问题编号、引用和正式清单保持原样；不为风格删除变量、处理步骤或指标。受访者原话和文献直接引语按原文保存，不能改写成更顺口的“原话”。

段落先给本段要说明的事实或判断，再按方法、结果及解释连接；有具体反证时保留反驳。必要限定放在读者作判断所需的位置：删除重复提醒不能扩大摘要或结论的适用范围。词频与句式命中只帮助定位待核对句段，不提供 AIGC 百分比或作者身份结论。

## 公式末尾与方程组后的变量域

本工作流的分析、写作及审查 AI 共用以下约定。

独立公式不自动追加装饰性点号，数学环境外也不单独留一个无信息的点。小数点、乘积点、导数点和省略号各有数学作用，按实际表达保留。明确模板或完整英文句子所需的句读另行核对；禁止用全局删除句点或删除公式尾部字符来清理。改了公式源时检查渲染与含义，不能把字节变化直接称为数学等价。

方程组后紧接一段“其中……”或“变量及定义域为……”，对应说明各变量的含义、连续/整数/二元等类型、取值范围、索引集合和相关时空域；有必要时列出单位、参数域、边界取等情况及未给定项。方程组末尾已有完整约束时，后文说明它们对应的变量和意义。不能把所有变量默认成非负、整数或概率，更不能为填格式补造上下界。

以下只示范一个**已规定非负连续分配量**的模型，不是用户题目的默认约束：

```tex
\[
\begin{cases}
x_1+x_2=B,\\
x_1\ge 0,\quad x_2\ge 0
\end{cases}
\]
其中，$x_1,x_2\in\mathbb{R}_{\ge0}$ 为连续决策变量，
索引集合为 $i\in\{1,2\}$；$B\in\mathbb{R}_{\ge0}$ 为给定总量，
其计量单位与各分配量一致。
```

检查器在普通模式也定位独立公式末尾的点号候选，并检查常见 `cases` 方程组后是否出现变量域说明提示。`domain_note_hint=true` 仅表示附近有范围用语或记号，`variables_verified=false` 表示尚未核实覆盖是否完整、边界是否正确。分段函数、复杂宏和式内已有约束需要人工判断，检查器不推导变量范围。

## 数模中的具体处理

以下是合成措辞示例，不能把例中的条件、数值或检验当成用户项目已经取得的结果。

| 情形 | 可采用的表达或动作 |
| --- | --- |
| 参数只在给定温度下标定，却被写成通用关系 | 写清标定温度和适用域；若结论离开该限定会被误解，摘要与结论也保留它 |
| “数值收敛不能说明现实预测准确” | 这是必要的概念区分，可保留；有实验数据时再分别报告预测检验 |
| 表题为“主要符号说明（一行一符号）” | 表题写“主要符号说明”，排版落实逐行列符号 |
| “根据 RESULTS_REPORT.md，本问已通过检查” | 核对真正支持的方程、数据和结果，再写其科学结论；文件存在与检查通过不足以推出模型有效 |
| “模型优点是有独立脚本、数据回读和清单” | 复现材料放在约定位置；模型优点评价其可解释性、可行性或性能，并给对应依据 |
| “模型可能或许在一定程度上有一些优势” | 根据实际比较写哪项指标、相同条件下怎样变化；证据不足时保留准确的不确定性或删除优势主张 |
| 某方案误差更小、耗时更长 | 两项指标及比较条件都报告；权衡如何影响推荐由题目目标决定 |
| 方案在一段参数区间最优，区间外排序改变 | 写清区间与边界的并列情形；限定是结果的一部分，应与推荐同处 |
| 英文稿 “may potentially suggest that X could possibly…” | 去掉重复保留词，按证据选 “is associated with” 或 “suggests”；相关关系不能改成因果关系 |

审稿模拟提出的问题也要分类：已经证实的错误要修；需要核实的问题去查证；可选扩展由本次范围决定。不能把审稿意见逐条搬成“模型不足”，也不能因改写更自信而删除影响核心结论的不利结果。

## 执行与复核

1. **确定范围。** 选择匿名论文的实际源文件及题注。附录受保护时排除对应文件；真实 AI 声明和工具详情按它们的用途与事实单独核对。
2. **先核对主张。** 关键句对应到题面、推导、原精度结果或文献。检查适用条件、比较口径、因果强度、可行域和最优性；缺证据不能靠改句式补上。
3. **按句子作用修改。** 保留有用强调和必要论证，减少重复辩解，清理对话与制作痕迹。确定问题位置及修改理由，只改相应句段，不另加结论、数值、案例或未做过的实验。
4. **逐句比较含义。** 原稿与修稿的数字、单位、正负方向、范围、阈值是否含等号、不利结果、引用和真实 AI 使用信息均保持准确。保留方程、代码、数据表及保护附录；数字相同仍需检查数值归属与比较对象。
5. **筛查并看成品。** 自动结果逐条判断，编译后通读摘要、图表题注、每问结论及模型评价；修订记录写在后台。

## 自动筛查的用法与边界

```sh
# 只选论文源；不要把仓库 README、审稿记录和 skill 文档当论文扫描。
python -X utf8 scripts/check_paper_voice.py paper/main.tex paper/sections --json

# 分文件附录不在此次范围时，排除模式相对于每个输入目录。
python -X utf8 scripts/check_paper_voice.py paper --exclude 'appendix/*' --exclude 'ai-details/*' --json

# 单文件 TeX 且正文后有字面 \appendix，只有保护附录时使用。
python -X utf8 scripts/check_paper_voice.py paper/main.tex --stop-at-appendix --json

# 用户要求润色表达或去 AI 味时，增加只读候选提示；支持 .tex / .typ / .md。
python -X utf8 scripts/check_paper_voice.py paper --style-review --exclude 'appendix/*' --json

# 局部改写完成后对照两个同格式源文件，不会覆盖或自动改写它们。
python -X utf8 scripts/check_paper_revision.py paper/original.typ paper/revised.typ --json
```

结果包含 `error_count`、`review_count`、具体位置和理由，以及实际选中的 `checked_files` / `excluded_files`。`error` 标出明确制作指令或助手自述候选，退出码为 1，仍需看上下文确认；内部文件引用和容易因研究对象产生歧义的制作词列为 `review`，退出码为 0 但 `review_required=true`。`--style-review` 额外定位有限的对举、提示语、叠加保留词与段首回指候选，均只供复核，不提高为关键词禁令；默认不启用这些风格候选，公式规范提示独立生效。两类均不自动删改原文。候选由本轮代理对照上下文和证据判断，信息充分时直接处理，不要求逐条向用户确认。缺少源或排除后无文件退出 2，不能报成检查通过。

工具忽略 TeX 注释及若干常见代码块、Markdown 围栏代码和 HTML 注释，并处理 Typst 行注释及嵌套块注释；保留原行号。风格候选另外避开常见数学环境、Markdown 标题/清单/表格/引语。它不展开 `\input`、`\include` 或 Typst include，不理解自定义宏、条件编译或所有格式语法；Typst 的函数式表格和复杂内容块仍须人工核对。须把实际正文分文件一起传入，正文/附录边界不明时先确定真实范围。声明里的提示词、代码示例等按上下文人工判断，不能从措辞筛查推断真实 AI 使用情况。

改写检查器比较字面数值顺序、常见单位、关系符号、公式、引用、标题、常见表格和代码；识别到的字面附录及 AI 使用声明起始处之后的内容按保护尾部对照。`changed_protected_groups` 非空时退出 1，先核对变动；限定、否定或统计判断词变化时给出 `review_required`。退出 0 仅表示这些不变项通过，不证明语义等价、归属正确或科学结论有效。自定义宏、多文件依赖、中文数字、罕见单位及复杂排版须另行核对。例文与实际检查范围见[局部改写示例](../examples/paper-revision/cases.json)。

这项筛查定位有限的制作痕迹，不验证数学正确性、全部引文、整体自然度或作者身份，不产生 AIGC 百分比，也不保证通过某种 AI 检测。无证据夸张、模糊指代和重复防御主要依靠上述内容复核。

来源版本、适配范围与许可集中保留在[写作来源记录](../LICENSES/writing-sources/README.md)。本节为本工作流的数模适配入口，无需另装其他写作 skill。
