# 市调理论、测量与实证分析

用于研究设计、问卷、统计分析和报告阶段。目标是把研究问题连接到实际变量、可识别方法和可复算结果；不把方法名或表格数量当研究深度。用户已有框架时先核对适用性，保留可用部分。

## 先定研究任务和证据

代理依据实际材料在项目中建立`reports/method-plan.json`，不要求用户先写JSON。记录研究问题、分析单位、真实来源、问卷版本、变量类型/编码、条件题、构念与题项对应、比较方向、方法候选与采用理由、缺失处理、效应量/区间、检验家族、验证划分和预期表图。数据审查后更新采用状态，不能为得到显著结果再改方向、删样本或换家族。

先区分描述、结构关联、预测、干预因果和定性解释。横截面相关、回归、SEM或QCA不自动识别因果；实际使用、试用意向、付费意向、金额上限和已付款分别测量。AI情境、预调查、真实回收、外部评论与行为日志分开；角色覆盖和模型会话隔离不证明现实总体代表性或统计独立。

## 理论框架按问题选择

| 框架 | 适合的问题 | 进入方法前核对 |
| --- | --- | --- |
| SOR | 环境或服务刺激经内部认知/情绪判断与反应对应 | S、O、R各自定义；刺激有无实际变异；时序与可能混杂；内部判断和行为区分 |
| TAM／UTAUT | 技术接受、使用与任务条件 | 有用性、易用性、绩效/努力期望等与本题相关的构念；实际测量而非仅换名 |
| TPB | 态度、主观规范、感知行为控制与意向/行为 | 三类构念分别测量；时间范围与真实行为资料；不能用态度单题替代全部构念 |
| 感知价值／风险／信任 | 价值收益、代价和风险条件下的选择 | 概念区分、量表内容、共同来源、内生性与实际决策指标 |
| 定性主题或过程框架 | 访谈/开放回答中的决策过程与机制线索 | 真实原文、编码规则、反例、编码分歧及匿名溯源 |

不同时堆叠全部理论。说明选用框架解释什么、遗漏什么，与问卷和统计方法分别对应。

## SOR从概念到可检验研究

SOR的经典来源为Mehrabian与Russell《An Approach to Environmental Psychology》（MIT Press，1974），原研究强调环境、情绪及趋近/回避反应。将信任、感知价值等认知变量放入O，是当前研究的情境化扩展，要说明理论理由，不能称经典原作已验证这些题项。

1. **概念框架**：列S、O、R定义、潜在方向和替代解释。框架图标明拟议关系，不标未估计的路径系数。
2. **测量模型**：逐构念列题项、量尺、来源、改写/翻译、适用对象、内容审查和预调查。反映式与形成式的判断来自构念定义，不根据哪个模型拟合好临时切换。研究者自编题项写清草稿状态，不标“成熟量表”。
3. **结构模型**：在测量和可识别性成立后，才估计路径、中介、调节或组间差异。共同固定情境没有S的差异，不能从该批数据估计S→O路径。单题可以作为观察变量分析，但没有多题测量信息时不补造alpha、CR、AVE、HTMT或潜变量因子。
4. **后续验证**：需要刺激效应时，设计实际可实施的操纵/随机分配和操纵检查；观察研究则说明暴露测量、时序、混杂与识别限制。中介重抽样只反映给定模型下的不确定性，不能替代因果识别。

新题项和实施方案另存，不覆盖已定稿问卷，不给旧回答补写新题答案。规划样本量依据最小有意义效应、事件数、模型复杂度、抽样/聚类、功效与可行性；不用“PLS适合小样本”或单一倍数法跳过设计。

## 方法选择与进入条件

| 方法 | 最低需要 | 应报告的结果 |
| --- | --- | --- |
| 描述／多重响应 | 实际记录、编码、分母和分支 | 有效数、频数、人数比例/次数比例、缺失/跳题、满选率；有序题优先分布和分位数 |
| 交叉表／精确检验 | 两变量的逐条配对；检查常量、稀疏格和来源 | 原始格数、组内比例、效应量、适用区间、检验定义和多重比较；不是只报星号 |
| 秩关联／非参数比较 | 有明确顺序，成对样本和并列值处理 | ρ/τ或分布差异、实际n；重排/精确方法及种子/次数，常量返回未定义 |
| 二元／有序／多项回归 | 匹配结局类型，足够事件、变异和参数支持 | 编码/参照、系数/OR、区间、分离/共线性、样本与诊断；不得将名义编码直接当线性分数 |
| Firth或其他正则方法 | 目标和惩罚明示，稀疏/分离问题可解释 | 与普通估计区分、惩罚及不确定性方法、敏感性；不能把有限系数等同于信息充足 |
| EFA／CFA／信效度 | 合理题组、变异、测量定义和模型识别 | 因子/载荷、误差及适用信效度指标；alpha不是单维性或真实性证明，形成式不照搬反映式阈值 |
| CB-SEM／PLS-SEM | 测量、结构、识别、样本/功效和估计假设 | 测量质量、路径及区间、拟合或预测评估、替代模型；按方法目标选择，不以软件名定方法 |
| 中介／调节 | 变量和时序理由、交互项或间接效应定义 | 直接/间接/交互效应、区间、调节取值范围、混杂和识别；显著路径拼接不等于中介成立 |
| fsQCA | 实际案例、构念、理论校准锚点与可辨识配置 | 校准、必要/充分条件、真值表、一致性/覆盖、矛盾与阈值敏感性；不称净效应或因果认证 |
| 聚类／画像 | 适合变量类型的距离、分支/缺失处理和稳定性 | 算法、类数选择、稳定性、样本映射和外部解释；分组定义变量不能再作为独立验证 |
| IPA／Kano／联合分析 | 各方法所需的成对量尺/正反题/设计属性组合 | 实际输入、估计与不确定性；普通“看重哪些”单题不能直接改成Kano或IPA |
| 预测模型 | 独立验证或合理重抽样、足够结局、泄漏检查 | 基线、校准/概率损失、少数类指标与适用范围；分类准确率不能单独证明有效 |

同一主体重复记录、同一调查点或团队聚类时，按来源和设计考虑配对/聚类估计与划分；不能把所有行默认当独立。条件于结局才显示的题不能反过来预测其前置结局；支出、后续选择和目标衍生字段同样检查泄漏。

## 可用的计算助手

`scripts/survey_empirical.py`读取当前问卷导出、同来源`records`和代理建立的显式分析计划，生成11类可选结果表、JSON与输入/文件SHA清单。只计算计划中有实际支持的部分，不估计SEM或构造潜变量。

```text
python scripts/survey_empirical.py --questionnaire 当前问卷.json --data 同版答卷.json --plan 分析计划.json --out 新结果目录
```

计划中的`outcome`给出实际题号及`positive`/`negative`编码；`contrasts`给出二元单选题、`exposed`/`reference`及解释；`ordinal`给出由低到高的编码列表；`groups`使用原问卷维度ID；`rank_pairs`指定有序题对；`multiple`指定不依赖结局显示的多选题；`cooccurrence`从这些题中选择。`conditional_number`和`price_group`用于适用分支金额描述。`seed`、`resamples`明确写入计划，当前脚本预算范围为999—199999次。代理按本题实际题号建立计划，不照搬示例研究的Q号、96行或比较方向。

输出包括变量支持度、有序题分位数、2×2 Fisher及条件OR精确区间、组间固定边际Pearson条件检验、有序题重排、多选差异及共现、简约Logit、留一诊断和条件金额。小型Rx2表可枚举时用精确尾概率，并以蒙特卡洛复核；超出预算用带次数、种子和误差的重排参照。此Rx2检验按Pearson统计量排序，不冒称概率排序的广义Fisher检验。

脚本中的Firth解析估计**仅适用于截距加一个二元预测变量**；不接受多变量Firth、任意SEM或加权/聚类推断。二元组内加0.5在这个饱和二组模型下对应Jeffreys惩罚，不能推广为所有回归都加0.5。普通MLE在零格分离时不输出伪有限估计；条件精确OR区间、普通Wald区间和Firth点估计分别标识，不能混称一种模型的区间。

默认新目录。`--overwrite-generated`仅在输入SHA未变、原输出仍与旧清单相符时替换已生成结果；输入变化或用户编辑后另存版本。清洗、抽样、加权、多源分离和字段匿名化须在进入本助手前按研究合同完成。

## 统计表与正文合同

按问题选表：样本/分支、构念题项、变量分布与变异、信效度（适用时）、交叉及效应量、模型估计与诊断、分组差异、稳健性和验证。不是每篇都强制全套；同一结果换几种表面排版不算新增证据。

每张表保留标题/编号、分析单位、来源、n和分母、变量/参照、单位、方法、区间口径、缺失/跳题和对应结果文件。表间共用的来源与假设集中说明，避免逐行堆免责声明；当前表特有的稀疏性或分母仍就地说明。科学软件实际执行什么就写什么；Python/SciPy输出可以采用规范三线表，不得冒称SPSS/Stata/AMOS/SmartPLS已运行。

多重比较先确定家族。完整保留原始p及校正p、不定义或常量项、实际检验个数；不能只列显著项目、删除未显著结局或看到结果再改用单侧检验。有限样本/非概率来源下，p和区间的参考模型与科学外推边界分别交代。

预测验证先预定比较集、基线、阈值和损失，逐折重拟合，预处理与调参不得接触验证目标。报告概率损失、少数类召回和校准等与任务相关指标；未做外部验证时不称跨地区或现实市场预测通过。稳健性必须改变具体假设/参数/样本处理并对照实际结果，不用泛泛文字替代。
