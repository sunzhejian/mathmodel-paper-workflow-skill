# 研究背景、政策与国内外文献综述

用于选题、研究设计、报告与答辩的证据准备，沿用当前主题和对象。研究背景回答“为何值得研究”，述评回答“已有研究知道什么、在哪些条件下成立、本项目补什么”，最后连接研究问题、变量与问卷。不要将政策篇幅、截图数量或引用数量作为完成标准。

## 政策与现实背景

先根据行业、地区、对象与时间范围检索国务院、主管部门及相关地方政府官网。区分原始文件、官方转载、政策解读与新闻报道；记录标题、发布机关、文号、原文日期、网页发布日期、生效日期、适用范围、是否查到修订/废止及本次访问时间。只访问发布页不能证明文件仍现行有效。政策目标、规划值与已实现数据分开，政策支持不能代替需求、采纳率或市场规模的实际证据。

截图须来自真实浏览器页面，包含可识别的官网栏目、文件标题及相关内容。使用当前实际工具：桌面工作区先`get_interaction_plugins`、`browser_open`、`browser_state`，再用`browser_save_evidence(tab_id,state_id,request_key,category:"policy")`保存。每次保存使用稳定请求编号；它留下原始视口PNG、DOM文字、URL、访问时间、滚动位置、像素与SHA。取证期间跳转或引用失效先重新读页面。正文较长时滚动后分段采集，不能把单张视口截图称为全文。验证码、错误页、搜索摘要不作政策原文；不能使用图像生成、拼接改写或去掉官网原有标识来冒充截图。模型不能看图时可存证，但不声称已视觉核对。

截图只证明访问时看到的页面。正文使用简短图注，如“某政策发布页（发布机构，访问日期）”，附可点击URL；截图不替代正式文件引用。原截图和用于排版的阅读版分开，保留原图SHA，不在原图上另加装饰水印。

## 国内外研究现状

按研究主题建立中英文关键词与检索式，保留检索来源、日期、时间范围、纳入/排除理由。优先期刊原站、出版商、作者机构、可核对的DOI和原始论文；按可用能力使用`list_connectors`、`search_references`、`lookup_reference`和`import_reference`。连接器未启用时可用受控浏览器查原始来源，不假定已接通知网或已读付费全文。

逐篇核对作者、题名、年份、期刊/出版社及DOI或稳定链接，区分预印本、正式发表版、勘误与撤稿。阅读范围登记为metadata、abstract、selected_sections或fulltext；只有摘要时不补写摘要未给的方法、样本、系数或局限。国内/国外分类说明依据，不能只凭作者姓名推断国别。

述评矩阵围绕主题、对象与样本、理论/构念、方法、主要发现、适用条件与局限、对本项目的启发。正文先比较同一主题的一致与分歧，再解释对象、测量和方法为何不同，最后提出有依据的研究空白。避免“国外较成熟、国内起步晚”式无证据判断，也不逐篇堆作者年份。变量与问卷题项说明来自何种研究或政策关切；不得把量表改写后仍称原量表已验证。

## 接入专属计划

主对话用项目文件工具建立`reports/research/review.md`及`reports/research/sources.json`，再调用`register_survey_research`，用户不必手写内部JSON。清单格式如下，示例字段不是已核验结果：

```json
{
  "schema_version": 1,
  "review": {"path":"reports/research/review.md","sha256":"读取实际文件后填写64位SHA"},
  "search_log": [{"query":"本主题关键词","source":"实际检索来源","date":"实际检索日期"}],
  "sources": [{
    "id":"P01", "category":"policy", "title":"实际标题", "url":"https://实际来源网址",
    "publisher":"实际发文机关与转载关系", "date":"原文与网页日期分开记录",
    "reading_scope":"selected_sections", "capture_id":"browser_save_evidence返回的实际ID",
    "findings":"实际读到的相关内容摘要", "limitations":"生效状态与适用边界",
    "relevance":"与本研究问题、变量或问卷的联系", "evidence_files":[]
  }]
}
```

文献来源category取domestic或international；可登记authors、identifier、method、sample、variables、findings、limitations、relevance和classification_basis。未取得官网截图的政策保留待补状态。清单中的研究者阅读声明不会自动成为全文或科学核验。

登记后文件、截图和述评指纹接入阶段上下文。更新清单并重新登记会使依赖的旧稿需复核；实际文件SHA变化时停止使用旧材料，保留旧稿及已完成候选，不重新发出问卷或模型作答。完整报告单列“国内外研究现状与述评”，背景中的政策、述评中的文献和问卷依据与参考文献逐条对应。正式排版检查截图清晰度、图注、编号与参考文献格式。

其他宿主使用其已有检索、浏览器截图、文件与书目工具完成同样证据链，不要求安装本工作区或使用上述固定工具名；工具不可用的部分如实保留待补状态。

专业书目核对与文献语种按`reference-integrity.md`执行；自动网络数据与NLP方法按`text-research.md`接续，保留实际来源与阅读范围。
