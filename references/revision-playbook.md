# 多轮反馈的执行细则

用于已有论文继续修改。一次简单措辞修改不必建立完整台账；多轮、多人或多文件交付时使用 [修订记录模板](../assets/revision-record.md)。只加载本次涉及的小节。

## 1. 确定基线与修改范围

最新明确指示优先于旧约束。例如“28%”改成“20%”，更新阈值而不是保留两套门槛；“附录不动但加页码”表示保护内容，页脚只允许已授权的页码变化。

接手时先回答四件事：用户指定哪份文件？哪份是可编辑源？哪些内容已手动修改？此次交付是 PDF、Word 还是两者？从现有上下文可知的不要重复询问。源与 PDF 不同，以用户指定的内容为准；不直接拿旧源覆盖新附件。

将反馈转成具体动作，给每项保留原句或位置。例如：

| 反馈 | 实施位置 | 完成证据 |
| --- | --- | --- |
| “摘要加粗重要结果” | 摘要源中的已核验方法与主结果 | 编译后摘要页；数值对应结果文件 |
| “18—20 页空白多” | 用小节名、图号定位，不只依赖旧页码 | 新 PDF 对应页的留白报告与原尺寸预览 |
| “公式分散到每问” | 逐问方法小节，共享理论保留必要部分 | 每问都有与实现一致的核心公式和参数说明 |
| “附录不动” | 原 PDF 附录页单独保护 | 拼接后渲染、文本逐页比对 |

结果状态只用 `待处理 / 已修改待验证 / 已验证 / 受阻 / 被新要求替代`。编译成功只能把编译项标为已验证，不能同时把内容、Word 和附录都标为通过。

## 2. 每问内容的最小完整单元

每问包含“本问条件与未知量 → 模型/判据 → 参数与范围 → 求解 → 主要结果 → 解释与检验”。不是给每问机械塞相同数量的公式。

- 共享守恒律、离散方法在前文集中推导；每问写清本问如何具体化，例如固定/移动区域、不同系数或终点判据。跨问不适用的物性不能沿用。
- 方程组用同一个左大括号组织确实需要联立的关系；不同情景的独立公式不为视觉效果强行合并。
- 范围来自题面、推导和代码。固定域可写 `0<r<R₀, t>0`；移动域可能为 `0<r<R(t)`；材料坐标可能为 `0<x<1`。这里只是格式例子，不能据此给任何方程套上相同范围。
- PDE 内部适用范围、初始条件的 `t=0`、中心条件的 `r=0`、表面条件的 `r=R(t)` 分别标注。经验式的标定范围无法确认时明确未给出，不编造上下限。
- 当公式后跟变量范围、条件或单位说明时使用适当逗号/间距；没有续接内容时遵循模板及用户要求统一句末标点，不能机械删掉公式内部有语义的逗号。
- 参数首次出现时就给数值与单位，不只写“单位见表 1”。区分无量纲数、物理单位、干基/湿基和不同质量分母。
- 黑框优先最终方程、最终判据或主要结果，编号放在框外并与正文引用一致；不圈住一整段解释。正文加粗以少量方法名、参数值和主结论为主。

公式从源到 PDF 要检查分数、上下标、括号、希腊字母及编号。Word 中检查实际公式对象而不只检查截图。公式字符串扫描只是线索，附录源代码或正文讨论代码时可能误报。

## 3. 摘要与措辞修订

摘要先概括对象、问题和方法，再按问题写主要方法与量化答案，末段说明已执行的检验及结论适用范围。篇幅来自有效信息，不套用往年论文的模型、数值或夸张评价。

维护 [逐问证据表](../assets/question-evidence.csv)：主数值对应源文件、输出字段、单位与展示规则。摘要、正文、表、图来自同一运行结果；修改舍入位数不改变原精度判据。

常见替换：

| 原表述问题 | 修订方式 |
| --- | --- |
| “根据附录”不能区分来源 | 写“赛题附录中的物性关系”或“本文附录 A 的程序”，准确区分赛题附录、数据附件和论文附录 |
| “正文显示四位所以保证四位准确” | 分别说明显示精度、离散误差和实际数据精度 |
| “多个软件验证了全过程”但只比过热方程 | 写明验证的是哪一子模型、哪些时刻和位置 |
| “模型优点是电子表可以追溯” | 将可追溯性放在复现说明；模型评价写有证据的结构、适用性或性能优点 |
| “表面含水率与空气湿度比都是 kg/kg 所以相等” | 先核对分母与定义；有效边界假设与实际平衡关系分开解释 |

去掉内部工作口吻不等于删除限制条件或真实 AI 声明。无法由现有数据辨识的因素保留为局限；用户要求更简洁时可以压缩，但不改成确定结论。

## 4. 图片、线稿与正文的协同修订

先定位图内空白还是图外空白。A4 四边 2.5 cm 时版心宽 16 cm；若画布宽 W、可见内容宽 w，为使可见内容宽达到 B，外框理论宽度为 `B×W/w`。该关系仅指导等比例排版；实际必须复核所有轴标、图例和引线，不按非白像素裁掉浅色线。

优先在绘图源中缩小无意义画布；框超出版心但可见内容未越界时，不为外框再缩小主体。放大导致整图推往下一页时，先检查浮动规则和图文顺序，再决定略缩图或拆分有独立含义的联图。不可横向拉伸数据图。

按高中物理题风格绘线稿时，明确观察方向、前后遮挡、中心线、尺寸线、矢量方向和对应方程。尺寸文字置于尺寸线旁的留白区；用引线避开主体，不让引线穿字。隐藏边用虚线，不能只因圆柱端面是椭圆就固定把某半边画虚线。

线稿是否有必要，用一个问题判断：它是否澄清了文字和公式难以直接说明的几何、边界或离散关系？只有“填空白”的作用时不新增。图下统计分析写进正文完整段落，图注保持简短。

## 5. 验收次序与停止条件

1. 内容与原精度结果一致后编译；修复缺字、错误引用和明显越界。
2. 按合同检查明确的正文物理页范围；查看整篇联系图，再放大重点页。不能仅抽查原有问题页，因为前页变化会影响后续分页。
3. 自动留白只量化整行连续空白带。大面积侧边空白、图内遮挡、低对比文字、错误透视仍需人工判断。阈值达标且视觉没有问题后停止无收益的调整。
4. 同一成品同时满足正文页数、留白、内容与图片清晰度；不能拿不同版本分别通过的报告拼成一次验收。
5. PDF 与 Word 各自验收；最后接回原附录，核对连续页码；按同一版本的白名单打包。
6. 最终说明包含成品链接、实测页数与检查范围、仍未通过的项目。未执行的工具或检查不写成完成。

若约束冲突，先完成可行改动并说明具体冲突，如“保持当前字号与完整表格时仍多一页”；不要偷偷缩小文字、删除必要论证或修改用户保护区域。确实需要用户选取舍时给具体可审阅方案。
