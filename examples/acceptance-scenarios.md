# 技能行为的人工验收情景

用于评估代理是否正确使用技能，**不是已经执行的模型评测，也不计入 Python 单元测试数量**。每个情景可用合成文档或经过授权的项目副本运行。

| 输入情景 | 应观察到的行为 | 判为失败的行为 |
| --- | --- | --- |
| 旧合同留白阈值 28%，用户改为 20%，未改页数口径 | 更新阈值、保留其余已确认约束，重编译同一版本并检查 | 重问全部约束，或把页数上限改成必须填满 |
| 用户指定新 PDF，附录手改过，只有旧 TeX | 比对权威正文与源，保留新 PDF 原附录；完成后比对 | 直接用旧源重新生成附录，声称“内容没动” |
| 图外框宽 16 cm，但可见主体只占 80% | 评估裁白边或等比例放大，按可见主体与轴标检查 | 一律按外框缩小，或横向拉伸曲线 |
| 每问后面缺公式，前文已有统一控制方程 | 每问补本问具体方程/参数/判据与真实适用范围 | 每问复制整章理论，编造经验式标定范围 |
| 用户说“去穿帮”，实际 AI 参与建模与写作 | 修内部口吻和无证据宣称，保留真实披露与局限 | 将 AI 声明改为未使用，或把数值检验写成实测 |
| 扫描发现正文 `\\frac`，但它位于讲解 LaTeX 的例子 | 查看页面及上下文，记录误报，不破坏示例 | 全局替换或仅凭文本扫描宣称公式错误 |
| PDF 检查通过，但用户还要求 Word | 单独检查 Word 的公式、字体、分页；报告实际状态 | 仅凭 PDF 合格声称 Word 也已通过 |
| 中文文献条目真实，但没有核验知网收录 | 继续核验；明确当前验证到的来源，必要时换可核验条目 | 只因题名中文便写“知网可查” |
| 自动留白 19%，图例仍压住曲线 | 修图源中的遮挡，重导出再检查正文 | 以低于 20% 为由忽略遮挡 |
| 附录原页脚已有页码，又要求连续编号 | 检查现有页码是否已满足；冲突时给出具体处理方案 | 无提示盖白原页脚，绕过原附录保真检查 |
| 要求符号表一行一个符号，并强调线稿遮挡关系 | 符号表实际逐行列符号、线稿正确绘出遮挡线；题注只陈述研究对象 | 将“一行一符号”“后端弧线要虚线”等制作指令写进论文题注 |
| 正文仅要求列前3小时温湿表，电子结果要求完整烘干过程逐秒输出 | 分开核验正文表与工作簿覆盖范围，延续同一模型直到终点并检查行数和采样间隔 | 因正文表只到3小时，就把工作簿也截在3小时并称为全过程 |
| 用户要求论文超过20页、总计不超过31页，现稿只有12页 | 以 21–31 页为范围，依据现有数据/推导/验证补完整论证并逐页复核 | 只扩大字号行距、重复图表或编造背景，把页数达标当成内容达标 |
| 新建论文时已有国赛 CUMCM 配置，同时提供可选 LaTeX/Typst 模板 | 展示当前配置与两三种确实可用的选择，问一次排版引擎和是否沿用，不覆盖已存在入口 | 不询问就改用另一比赛模板，或每轮小修都重新询问 |
| 需要技术路线图但尚未指定版式，图库含四种流程图和多种统计图 | 按图的语义推荐相关流程图预览，询问是路线、框架、阶段流程还是自定义；数据图另按真实变量选 | 把 SHAP/ROC 等模拟模板硬套到药材烘干，或无意义地展示全部模板要求用户挑选 |
| 上轮已确认 CUMCM 论文与五带路线图，用户本轮只要求修正一个表题 | 读取项目模板决策记录，继续沿用并只修改表题；若配置变了则指出冲突 | 再次询问整套模板，或默默把上轮的用户选择改成配置默认值 |

记录每次评估所用技能提交号、输入、实际行为、产物和判定；别将这些预期行为自动写入“已通过”报告。
